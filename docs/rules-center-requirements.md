# AI 规则中心 — 需求基线

## 产品定位

本机 AI 配置管家：先让人「看得见、比得清、改得动」全局资产；再支持「一处改、多处同步」；最后覆盖「打开某个项目仓库」的项目级规则。

## 术语

| 术语 | 含义 |
|------|------|
| rule | 常驻规则 / 约定（如 `.mdc`、`AGENTS.md`、`CLAUDE.md`、`user_rules.md`） |
| skill | 按需技能包（如 `skills/*/SKILL.md`） |
| agent | Agent / 子代理定义 |
| prompt | 提示词 / 命令模板 |
| other | 未归类资产 |
| slug | 归一化名称，用于跨工具对照 |
| 漂移 | 同 slug 在多工具中内容不一致 |

## As-Is 能力

| 能力 | 说明 |
|------|------|
| 全局扫描 | `~/.cursor`、`~/.claude`、`~/.codex`、`~/.trae*`、`~/.qoder*` |
| 筛选搜索 | 按工具、类型、关键词 |
| 预览编辑 | 应用内读/写，脏检查 |
| 访达/外部打开 | 系统集成 |
| 跨工具对照 | 按 slug：`identical` / `same-name` / `single` |

## 用户故事（Top 10）

1. 作为多工具用户，我希望一眼看到各工具有多少规则/技能，以便盘点配置。
2. 作为混用用户，我希望发现同名但内容不同的规则，以免行为漂移。
3. 作为维护者，我希望并排查看两份内容，快速决定以哪边为准。
4. 作为新用户，我希望用模板新建 `AGENTS.md` / `SKILL.md` / `.mdc`。
5. 作为迁移用户，我希望把一份规则同步到其他工具目录。
6. 作为整理者，我希望被提示过长、重复、缺失入口文件的问题。
7. 作为开发者，我希望打开某个项目，查看仓库内 AGENTS.md / `.cursor/rules`。
8. 作为编辑者，我希望在应用内改规则并保存，或跳到外部编辑器。
9. 作为排查者，我希望按工具/类型过滤并搜索路径。
10. 作为安全用户，我希望只能读写允许的规则目录。

## 非目标

- 云端规则市场 / 账号同步
- 自动改写业务代码
- 完整 Git 式行级 diff 引擎（第一期用并排预览即可）
- 替代各 AI 工具自身的配置 UI

## 分期

1. **第 1 期**：健康度体检、对照组并排预览、模板新建
2. **第 2 期**：跨工具同步
3. **第 3 期**：项目目录扫描
