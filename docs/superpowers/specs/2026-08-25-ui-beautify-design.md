# CZTool 界面美化设计

**日期:** 2026-08-25  
**状态:** 已定稿（待实现计划）  
**范围:** 全站视觉与壳层结构（主壳 / 工具箱 / 弹窗 / 历史 / 设置）

## 目标

将 CZTool 从「深色窄栏 + Element 默认壳 + Emoji 卡片」统一为 **清爽工具台**：浅色蓝灰、双栏导航、柔色图标砖，在不改业务逻辑的前提下提升桌面工具的观感与层次。

## 已确认决策

| 项 | 选择 |
|---|---|
| 覆盖范围 | 全站：主壳、工具箱、弹窗、历史与设置 |
| 气质 | 清爽工具台（浅色、淡蓝点缀、圆角卡片） |
| 壳层结构 | 合并为双栏（去掉 50px 深色窄栏） |
| 图标 | 柔色图标砖（Element Plus 图标 + 淡色圆角底） |
| 落地路径 | 壳层重建 + token 贯通（非浅层换肤、非大抽组件） |

## 架构

### 壳层（`App.vue`）

- 移除最左侧 50px 深色 `main_menu`。
- 单一侧栏（默认约 220px，可拖拽约 200–320px）：
  - 顶部：CZ 标识 + 产品名「CZTool」
  - 导航：工具箱 / 历史记录 / 设置（选中态实心主色胶囊）
- 右侧主区：
  - 顶栏：当前页标题 + 窗口控制（最小化 / 最大化 / 关闭）
  - 内容区：动态组件（ToolBox / History / Settings）
- 拖拽：侧栏顶与主区顶栏为 `-webkit-app-region: drag`；导航与按钮为 `no-drag`。
- 侧栏宽度持久化可选；首版可不做，保持内存态即可。

### Token（`src/style.css`）

延续并贯通现有 `--cz-*`，不另起主题名：

- 背景：`--cz-bg` / 轻微径向 + 纵向渐变
- 表面：`--cz-surface`、半透明 elevated
- 主色：`--cz-primary` `#3b82f6` 及 soft / hover
- 文字：slate 阶梯（primary / secondary / tertiary）
- 圆角：sm 12 / md 16–18 / lg 24
- 阴影：仅 `--cz-shadow-sm` / `--cz-shadow-md`
- 过渡：约 200–220ms

Element Plus 通过 CSS 变量或有限全局覆盖贴合上述 token（按钮、对话框、标签、分页），不引入新 UI 库。

### 签名手法：Soft Tile

工具入口统一为：

1. 白底圆角卡片 + 细软边框  
2. 左上或顶部柔色圆角图标砖（Element 图标）  
3. 标题 + 一行次要说明  
4. 悬停：轻微上浮 + 边框贴近主色软边  

「更多功能 / 开发中」降低不透明度，不伪装为可用入口。

## 页面与组件

### 工具箱（`ToolBox.vue`）

- 响应式网格（约 2–4 列，随主区宽度变化）。
- Emoji 替换为 Element Plus 图标 + 每工具固定 soft 色（蓝 / 青 / 绿 / 琥珀等，语义固定、不炫彩）。
- 业务：仍通过现有 dialog 开关打开；逻辑与 IPC 不变。

### 弹窗（`dialogs/*Dialog.vue`）

- 圆角白底、标题清晰、单一主 CTA、次按钮弱化。
- 统一内边距与表单间距；保留 `destroy-on-close` 与现有事件。
- 不改解析 / 请求 / 历史写入逻辑。

### 历史（`History.vue`）

- 行式列表 + 模块 / 状态软标签（成功 / 失败 / 运行中用语义色 soft 底）。
- 行 hover 浅蓝底；空态与加载有可读文案。
- 分页样式贴合 token；详情弹窗与工具弹窗同视觉语言。

### 设置（`Settings.vue`）

- 同表面与间距体系；表单项对齐；避免无意义多层卡片。

## 动效与无障碍

- 导航选中、卡片悬停、弹窗显隐使用短过渡（~200ms）。
- 尊重 `prefers-reduced-motion`：减弱或关闭非必要动画。
- 保留可见 `:focus-visible`；窗口按钮与导航可键盘聚焦。
- 主色与正文对比度保持可读。

## 明确不做

- 不引入新 UI 库或动画库  
- 不修改业务逻辑、IPC 契约、第三方接口 URL/解析  
- 不做深色模式  
- 不做炫光、多层装饰阴影、粒子  
- 不启用仍注释关闭的收藏夹  
- 不借机大重构无关模块或抽过度组件库  

## 主要改动文件（预期）

- `src/App.vue` — 双栏壳重建  
- `src/style.css` — token 补齐与 Element 覆盖  
- `src/components/ToolBox.vue` — Soft Tile 网格与图标  
- `src/components/History.vue` / `Settings.vue` — 视觉对齐  
- `src/components/dialogs/*Dialog.vue` — 间距与弹窗外观（按需）  

## 验收标准

1. 启动后为双栏浅色壳，无独立深色窄栏。  
2. 工具箱卡片为 Soft Tile（非 Emoji 为主视觉）。  
3. 历史 / 设置 / 弹窗视觉与壳层同一色板与圆角语言。  
4. 现有工具流程（打开 → 操作 → 历史写入）行为不变。  
5. 减小窗口宽度时网格可收缩，不出现严重横向溢出。  
6. 开启系统「减少动态效果」时无明显强动画。  

## 设计 thesis（一句话）

用双栏浅色壳 + Soft Tile 把 CZTool 收成一台干净的本机工具台，用贯通的 `--cz-*` token 统一 Element，而不是再贴一层皮肤。
